## 算法思想

**二分查找**

## 思路分析:

常规的二分查找操作，定义左右指针和 mid 指针，交替移动确定待查询目标元素的存在性，此后遍历整个数组，由于整个数组是非递减排好顺序的，因此相同的元素在索引上必然连续：

只需将所有的目标元素所对应的下标都压入向量中，此后取下标的第一个元素和最后一个元素作为返回向量的成员即可。

## AC代码如下:
```C++
# include <bits/stdc++.h>
using namespace std;

class Solution {
public:
    vector<int> searchRange(vector<int>& nums, int target) {
        int n = nums.size();
        if(n==1 && target==nums[0])
            return {0,0};
        int l = 0;
        int r = n-1;
        vector<int> res;
        vector<int>tmp;
        bool flag = false;
        while(l<=r)
        {
            int mid = l+(r-l)/2;

            if(nums[mid]>target)
            {
                r--;
            }
            else if(nums[mid]<target)
            {
                l++;
            }
            else
            {
                flag = true;
                for(int i=0;i<n;i++)
                {
                    if(nums[i] == target)
                    {
                        tmp.push_back(i);
                    }
                }
                break;
            }
        }
        // for(int ele:tmp)
        //     cout<<ele<<" ";
        cout<<endl;
        if(flag)
        {
  
            res = {tmp[0],tmp[tmp.size()-1]};
        }
        if(!flag)
        {
            res = {-1,-1};
        }
        return res;
    }
};
```
