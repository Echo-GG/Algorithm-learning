## 算法思想:

**pair<T1,T2>数据结构的运用**

## 思路分析:
通过维护一个现有的具有一一对应关系的 **pair<string,int> Map[]**, 来记录下各种数值下与之对应匹配的替换字符串(罗马数字)：由此维护了一个**基本计数单位表**。

Map数组内按数值从高到低排列pair对，采用循环从高位开始尝试读取基本计数单位，如果当前的基本计数单位大于待转换数字，则考虑下一个基本计数单位，直至满足小于的关系

(i.e. 基本数据单位第一次小于当前待转换数字)

此时，在原待转换数的基础上，减去这个基本单位，同时结果字符串 res (初始时置为空 "")，加上与该基本计数单位对应的字符串，即可完成一次“片段转换操作”。

( 由于 **1<=num<=3999** ： 因此不用担心重复片段过多的问题。)

如果某一时刻 num 减至 0 ，则代表转换全部完成，转换程序结束，返回对应的结果字符串。




## AC代码如下:
```C++
#include <bits/stdc++.h>
using namespace std;
const pair<int,string> Map[] = {
    {1000,"M"},
    {900,"CM"},
    {500,"D"},
    {400,"CD"},
    {100,"C"},
    {90,"XC"},
    {50,"L"},
    {40,"XL"},
    {10,"X"},
    {9,"IX"},
    {5,"V"},
    {4,"IV"},
    {1,"I"},
};
class Solution {
public:
    string intToRoman(int num) {
        string res = "";
        for(const auto&[val,str]:Map){
            while(num>=val){
                num-=val;
                res+=str;
            }
            if(num == 0){
                break;
            }
        }

        return res;
    }
};
```
