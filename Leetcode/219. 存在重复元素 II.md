## 算法思想

**哈希表的简单运用**

## 思路分析:

遍历数组中的所有元素；

没见过的元素存入哈希表，见过的就执行判断逻辑.

## AC代码如下:

```C++
class Solution {
public:
    bool containsNearbyDuplicate(vector<int>& nums, int k) {
        unordered_map<int,int> dictionary;
        int n = nums.size();
        for(int i=0;i<n;i++)
        {
            int num = nums[i];
            if(dictionary.count(num) && abs(i-dictionary[num] <= k))
                return true;
            dictionary[num] = i;
        }
        return false;
    }
};
```
