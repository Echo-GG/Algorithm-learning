## 算法思想

**双指针法**

## 思路分析:

考虑**双指针法**分别使用两个指针从头遍历字典中的字符串和目标串，问题变为判断字典中的当前字符串是否为目标串的子串。

选择符合条件的子串中较长的那一个，若有相同长度的则选择字典序较小的那个。

```C++
if(ptr2!=(int)n2)
  continue;
```

ptr2 表示在匹配字典中的当前单词 str 时，已经成功匹配到 str 的第几个字符(匹配进度), n2 是 str 的长度。

如果条件判断中的条件满足，则意味着当前的子串已经完全符合目标串的子串要求，有资格参与长短的比较和字典序的比较。

倘若这个条件未满足，则说明循环结束时 str 还没匹配完。

要么 s 已经扫完了 ptr1==n1，要么别的原因导致没把 ptr2 推到末尾 (i.e. str 不是 s 的子序列)。

e.g. s = "abc", str = "abcd"，显然这一组样例中，str不是符合题意的结果。

## AC代码如下:
```C++
# include <bits/stdc++.h>
using namespace std;

class Solution {
public:
    string findLongestWord(string s, vector<string>& dictionary) {
        int n1 = s.length();
        int n = dictionary.size();
        string res = "";
        for(int i=0;i<n;i++)
        {
            string str = dictionary[i];
            int ptr1 = 0;
            int ptr2 = 0;
            int n2 = str.length();    

            while(ptr1<n1 && ptr2<n2)
            {
                char ch1 = s[ptr1];
                char ch2 = str[ptr2];
                if(ch1 == ch2)
                {
                    ptr1++;
                    ptr2++;
                }
                else
                {
                    ptr1++;        
                }  
            }
            if(ptr2!=(int)n2)
                continue;
            if(n2>res.size() || (n2==res.size() && str<res))
            {
                res = str;
            }
        }

        return res;
    }
};
```
